How to use this visualizer

This tool teaches you how gzip compression works by letting you see the compressed binary data and the Huffman codes in real time.

For a deeper dive, check out this article on gzip internals.

1 Input — Type any text and the page will instantly show the compressed output.

pyflate2 / gzip Hello, world! ⓘ Help

2 Compression Stats — Shows how much the data was compressed. A positive diff means the compressed output is larger (common for very short strings).

13B → 33B (+20B, ×2.54) · Hover/tap bits to see their meaning

3 Hexdump — Binary representation of the compressed data. Hover/tap bits to see their meaning. Colors group bits that belong to the same symbol.

0a  f3  [11110011] .

offset   hex   [colorbits] ASCII

4 Selected Bits — Shows the binary and hex value of the bits you hover over. Gzip packs bits left-to-right byte-wise but right-to-left bit-wise — this display helps untangle that.

◆ Selected 11110011 (243, 0xF3)

5 Log — Step-by-step decompression log. Hover a log entry to highlight its bits in the hexdump, or hover hexdump bits to scroll to the log entry.

[91] found symbol 0x1e of len 8 mapping to 0x48
[91] found literal b'H'. r=72, hex(r)=0x48
[99] found symbol 0xa9 of len 8 mapping to 0x65

6 Huffman Tables — The two Huffman code tables used by the compressor. First table: literal/length codes. Second table: distance codes. More about Huffman coding.

Symbol   Code
0 (0x00)   EOF
1 (0x01)   80 ('P')
Symbol   Code
0 (0x00)   0
1 (0x01)   16
